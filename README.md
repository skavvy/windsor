# Windsor
Windsor is an open-source game made by me, skavvy for the Terra YSWS in Hack
Club. You can control the game with any combination of Up, Down, Left, and
Right. Reasonable defaults are provided for these (WASD, Arrows, Space and
Shift, etc.), but input settings are planned.

## Rewrite

## Controls & How to play
### NJMP
NJMP, or the N-Jump, is the signature move of Windsor. The name is
self-explanatory, each upgrade you get, N increases. You can flutter
N times per jump off of the ground.
use \[ W Space Up \]

### GPND
GPND, or Ground Pound is a fairly common move in 3D platformers, but in
Windsor it serves a tactical purpose. When you Ground Pound into a slope
or into a wall, you can gain a lot of horizontal momentum.
Use \[ S Shift Down \].

### RGHT
RGHT. Moving right.
Use \[ D Right \]

### LEFT
LEFT. Moving left.
Use \[ A Left \]
