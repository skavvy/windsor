# Windsor
Windsor is an open-source game made by me, skavvy for the Terra YSWS in Hack
Club. You can control the game with any combination of Up, Down, Left, and
Right. Reasonable defaults are provided for these (WASD, Arrows, Space and
Shift, etc.), but input settings are planned.
